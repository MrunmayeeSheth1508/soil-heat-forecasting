    Evaluated results so far

    Scope of the scores. The repo's stage-8 forecast scores apply to the original temperature targets (20 and 50 cm, hot-spell issues; see Project archive). The five-depth temperature-and-moisture models here are preliminary: gradient-boosted trees (trained 2019–2020, tested 2021, daily issues) and the GRU (trained 2019 to Sep 2020, early stopping on Oct–Dec 2020) is tested on the same 2021 issues. Ablation configurations are run for the trees; the GRU uses all inputs.
    The soil forecast describes conditions away from cable heating. This installation model calculates the additional local heating produced by the cable.
